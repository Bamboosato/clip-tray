# ClipTray

Windows および macOS のデスクトップブラウザで動作する、**完全ローカル完結型のスクリーンショット一時保存・グループ管理・OCR / バーコード読み取り PWA Web アプリ**です。

- **Web App:** https://clip-tray.bamboosato.com/
- **仕様書:** [docs/SPEC.md](docs/SPEC.md)

---

## コンセプト

作業中のスクリーンショットや参考画像を「ちょっと仮置きして、すぐ再利用し、用が済んだら自動で消える」ことに特化したブラウザ常駐型クリップトレイです。

- **完全ローカル保存:** サーバーやクラウド同期は持たず、すべての画像データ・メタデータはブラウザ内の **IndexedDB** に保存されます。
- **プライバシー保護:** 画像内の文字抽出（OCR）やバーコード／QRコード読み取りもすべてフロントエンド（Web Worker / WebAssembly）で完結し、画像が外部サーバーへ送信されることはありません。

---

## 主な機能

### 1. スクリーンショット即取り込み & 自動最適化
- **ペースト即保存:** 画面上のどこにいても `Ctrl + V`（Windows） / `⌘ + V`（macOS）でクリップボード内の画像を即座に取り込みます（テキスト入力欄フォーカス時は通常のテキストペーストを優先）。
- **ドラッグ＆ドロップ / ファイル選択:** 画面全体への複数ファイル同時ドロップ、またはヘッダーの「画像を追加」ボタンから取り込み可能。
- **自動軽量化:** Canvas API で長辺上限（デフォルト `1920px`、設定変更可）に合わせて縮小し、WebP（品質 `0.85`）と一覧用サムネイル（長辺 `400px`）を同時生成して保存します。

### 2. グループ（タブ）管理
- 初回起動時にデフォルトグループ `Inbox` を自動生成。
- グループの新規作成（アクセントカラー設定対応）、ダブルクリック／ボタンによるインライン編集、ドラッグ＆ドロップおよび左右ボタンによる並び替え、確認ダイアログ付き削除に対応。
- 「すべて表示」「ピン留め」「各グループ」でのフィルタリング（件数バッジ付き）や、カードのドラッグ＆ドロップによるグループ間移動が可能です。

### 3. 再利用・ライトボックス閲覧
- **ワンクリック PNG 再コピー:** カードの「コピー」ボタンやプレビュー中の `Ctrl + C` / `⌘ + C` で画像を PNG 形式へ変換してクリップボードに書き込みます（Safari / Firefox 互換の `ClipboardItem` Promise 渡し対応）。
- **ライトボックスプレビュー:** 原寸大表示、ボタン／マウスホイールでの拡大縮小（25%〜400%）、矢印キーでの前後移動、個別ダウンロードに対応。
- **インラインメモ & 横断検索:** 各画像にメモを付与でき、ヘッダーの検索バーでリアルタイムに絞り込めます。

### 4. フロントエンド完結 OCR & バーコード／QRコード読み取り
- **ハイブリッド自動解析:** 取り込み時にバックグラウンドの直列キューで自動解析（設定で手動のみにも切替可能）。
- **バーコード／QRコード対応:** `barcode-detector`（ZXing-C++ WASM）により、JAN / EAN-13 / EAN-8 / UPC / Code 128 / Code 39 / ITF / QRコード等を余白補完付きで高精度デコード。バーコード領域をマスクして縦縞ノイズを抑えつつ周囲テキストと統合します。
- **スクリーンショット向け OCR 前処理:** `tesseract.js`（日本語＋英語 `jpn+eng` / 英語のみ `eng`）を用い、暗背景（ダークモード）の自動輝度反転・コントラスト強調グレースケール・疎テキストフォールバック（`PSM.SPARSE_TEXT`）を実施。
- **閲覧・編集・検索:** ライトボックス内の OCR パネルで抽出結果の確認・手直し編集・テキストコピーができ、ヘッダー検索バーでメモと抽出テキストを横断検索（カード上に一致スニペット表示付き）できます。

### 5. 一時保存向けクリーンアップ & ストレージ管理
- **自動期限切れ削除（TTL）:** 設定モーダルから保存期間（`24時間` / `3日` / `7日（標準）` / `30日` / `オフ（無期限）`）を設定可能。
- **ピン留め保護:** 重要な画像をピン留めすると一覧上部に固定され、自動削除および一括クリアの対象外になります。
- **一括クリア & 使用量表示:** 表示中グループの「ピン留め以外を削除」ボタン、および `navigator.storage.estimate()` による使用容量目安を表示します。

### 6. PWA（デスクトップアプリ化 & オフライン動作）
- Chrome / Edge のインストールボタンや macOS Safari の「ファイル → Dock に追加」からスタンドアロンアプリ（`display: "standalone"`）として利用可能。
- Service Worker によりアプリ本体およびバーコード解析用 WASM（`zxing_reader.wasm`）を事前キャッシュし、Tesseract 資産も初回実行後にランタイムキャッシュすることでオフライン利用に対応しています。
- 新バージョン配信時は左下に更新通知バナーを表示し、任意のタイミングで安全に更新できます。

## キーボードショートカット

| 操作 | Windows | macOS |
| :--- | :--- | :--- |
| クリップボードの画像を保存 | `Ctrl + V` | `⌘ + V` |
| プレビュー中の画像を PNG コピー | `Ctrl + C` | `⌘ + C` |
| プレビューで前後の画像へ移動 | `←` / `→` | `←` / `→` |
| プレビュー・モーダルを閉じる | `Esc` | `Esc` |

## 技術スタック

- **フロントエンド:** Vite + React + TypeScript（`strict: true`）
- **スタイリング / アイコン:** Tailwind CSS v4 / `lucide-react`
- **ローカル DB:** `dexie` + `dexie-react-hooks`（IndexedDB）
- **OCR / バーコード解析:** `tesseract.js` / `barcode-detector`（`zxing-wasm`）
- **PWA:** `vite-plugin-pwa`（Workbox）
